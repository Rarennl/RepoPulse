Решение нельзя считать полностью принятым по исходному ТЗ.

## Интеграционные ограничения

1. **AppSec:** в публичной Swagger от 2026-09-16 нет API результатов SAST/SCA/secret scanning. Есть нормализация подтверждённых сканов и состояние unavailable, но нет живого сбора. Требуется официальный контракт или документированный CLI-интерфейс. Нельзя заменить своим сканером, успешным CI или произвольным JSON.
2. **Вся платформа:** доступны списки по организации, но не глобальный каталог/список всех организаций пользователя. SOURCECRAFT_ORGS — явный охват, не вся платформа.
3. **Credentials:** PAT и OAuth client credentials не предоставлены. Публичный Git проверен на трёх реальных репозиториях. REST без PAT вернул 401. Я ID и private Git/PAT реализованы, но не проверены с живой учётной записью.
4. **Основной рейтинг:** требует полных Security-данных; пока их нет, он пуст. Предварительные результаты доступны отдельным фильтром. Это предотвращает преимущество от неполноты данных.

## Аналитика

- README по дереву доказывает лишь наличие. Git-текстовые эвристики не запускают документацию и не проверяют лицензионные условия.
- Git анализирует default branch. Остальные ветки, LFS и submodules не скачиваются.
- TODO/FIXME — текстовая прокси без AST, возраст по blame строк. Переносы и переписывание истории могут менять результат.
- Комментарии и зависимости обходятся полностью только при ≤100 issues. При превышении latency/dependencies null. Backlog и closure рассчитываются по всем доступным задачам с ограничителем 100000 наблюдений медианы.
- Нет review bottlenecks, bus-factor, карты владельцев, сравнения, AI-summary и badge. История Score есть, позиции — нет.
- Лайки не влияют на Score; пустые коммиты исключены, активность насыщается. Sybil-авторы, фиктивные issues и массовое форматирование остаются риском.
- Сортировка likes/activity по snapshot последнего анализа, отображаемые metadata перепроверяются live; изменения между анализами могут визуально нарушить порядок.
- API не предоставляет атомарный snapshot всех ресурсов; сбор занимает интервал времени.

## Эксплуатация и проверка

- Docker daemon и PostgreSQL server в среде подготовки отсутствовали. Compose build/up не проверен; CI содержит этот gate. SQLite-тесты очереди не доказывают конкурентную работу Postgres SKIP LOCKED.
- Chromium не установлен, загрузка завершилась сетевыми таймаутами/502. Визуальная/browser E2E-проверка UI остаётся обязательной; синтаксис JS и API проверены.
- Реальной `src` в среде не было. CLI wrapper опционален, не является автоматической заменой REST. Предназначен для POSIX/WSL, использует process groups.
- 10000 файлов, 20000 коммитов и 501 MiB проверены синтетически как streaming/resource guard, не как live-анализ большого SourceCraft repo. Сервер может игнорировать partial clone: ресурсный бюджет даст missing.
- Git: 600 секунд / 1 GiB, blob≤1 MiB, чтение≤256 MiB, blame≤50 файлов. Весь REST job пока без общего deadline.
- Redis rate-limit простой, без fairness; Retry-After HTTP-date не разбирается, применяется обычный backoff.
- Discovery lock на час не продлевается. Для больших организаций нужны отдельные cursor-resumable discovery jobs.
- Общий счётчик leaderboard основан на SQL snapshot; перед выдачей строк перепроверяется видимость. Поэтому после отзыва прав возможны пустые места на странице до пересчёта.
- Нет панели администрирования, удаления аккаунта со всеми данными, автоматического backup и многоэтапной ротации ключей. До их реализации это не готовый публичный multi-tenant SaaS.
