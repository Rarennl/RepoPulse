От фактов к оценке

Один Score, шесть категорий и проверяемые основания для каждого вывода.

Веса категорий

Score = Σ(вес × оценка доступной категории) / Σ(вес доступных категорий)

Внутри категории применяется такая же нормализация по доступным метрикам. Округление выполняется до одного десятичного знака в конце расчёта.

«Нет данных» — отдельное состояние

Отсутствующий результат не превращается в ноль. Покрытие показывает, какая часть методики подтверждена данными. Предварительная оценка не участвует в основном рейтинге.

Никаких баллов за популярность

Лайки не участвуют в формуле. Активность ограничена числом недель с содержательными изменениями. Пустые коммиты исключаются.

Security — только SourceCraft AppSec

Наличие CI не доказывает безопасность. Без завершённых актуальных сканирований SAST, SCA и секретов показывается «Нет данных». Результаты запрашиваются через SourceCraft Security API. Если запуск не завершён или охват движка неизвестен, балл не выставляется.
